Production Release & Deploy Runbook

CRITICAL REQUIREMENT

Never deploy to production without an approved Pull Request and a green build in Jenkins.

Deployment Steps

We deploy using Kubernetes helm charts on Wednesdays at 06:00 UTC.

  1. Check the health dashboard at 
    https://status.internal.company.com
    to ensure no active outages.
  2. Trigger the deploy job in Jenkins: 
    build-deploy-prod-service
    .
  3. Run migration verification tasks: 
    kubectl exec -it deployment/payment-service-deployment -- npm run db:migrate:status

Deploy Metrics & Verification

Monitor Datadog dashboard for 15 minutes post-deployment. Ensure that:

Metric Expected Threshold Action if Violated
HTTP 5xx Error Rate < 0.05% Rollback immediately using helm rollback payments 1
API Latency (p99) < 250ms Check DB connection pool saturation in RDS graphs
